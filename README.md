# DevOutsource Tracker — Інформаційна система

## Призначення
DevOutsource Tracker — це вебпрототип інформаційної системи, призначеної для обліку та відстеження поточних завдань розробника, швидкої навігації по активних проєктах та моніторингу загальної статистики трудовитрат.

## Основні функціональні можливості
- **Перегляд даних:** Виведення списку призначених завдань із зазначенням їхнього коду, проєкту та поточного статусу.
- **Пошук:** Швидкий пошук завдань за назвою або унікальним ідентифікатором (кодом).
- **Фільтрація:** Відбір завдань за конкретним проєктом через випадаючий список.
- **Динамічна статистика:** Автоматичний перерахунок віджетів (кількість унікальних проєктів та загальна кількість завдань) залежно від застосованих фільтрів.

## Вимоги до програмного середовища
Для коректної роботи системи потрібен будь-який сучасний веббраузер (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge) із підтримкою HTML5, CSS3 та JavaScript (ES6). Додаткове програмне забезпечення не вимагається.

## Порядок запуску
1. Завантажте файли проєкту (`index.html`, `style.css`, `app.js`) на локальний комп'ютер.
2. Відкрийте файл `index.html` у веббраузері. 
3. Система повністю автономна на стороні клієнта і не потребує налаштування локального сервера чи баз даних.

## Відомі обмеження системи
- **Статичні дані:** Поточна версія є прототипом інтерфейсу (Front-end), тому дані жорстко закодовані у вигляді масиву у файлі `app.js`.
- **Відсутність збереження стану:** Оскільки система на цьому етапі не використовує бази даних або `localStorage`, будь-які зміни або застосовані фільтри скидаються після перезавантаження вебсторінки.
- **Обмежена інтерактивність:** Система фокусується на пошуку та фільтрації; функції створення нових завдань або редагування наявних знаходяться на стадії розробки.
